# 练了么

> 一个为个人力量训练设计的简洁 PWA：制定下一次训练、记录真实完成情况，并持续回顾自己的训练进步。

[English README](./README.en.md)

## 能做什么

- 根据训练模板和历史记录生成、调整并推送下一次训练计划
- 记录每组重量、次数、RIR 和完成状态，并自动保存未完成输入
- 临时调整本次训练组数，不影响长期训练模板
- 查看训练历史、动作趋势和身体数据
- 通过 ChatGPT 提出并确认训练模板修改
- 可选使用 Private GitHub 仓库进行多设备同步
- 支持 JSON 备份，并可安装为手机或电脑 PWA

## 怎么用

最常用的流程很简单：

1. 打开 **计划** 页面，选择一个训练模板。
2. 查看系统根据历史记录生成的下一次训练建议。
3. 根据当天状态调整重量、次数或组数。
4. 点击 **推送计划**，把它设为当前待训练计划。
5. 打开 **训练** 页面，边练边填写实际完成的数据。
6. 训练结束后保存，本次记录会进入 **历史**，以后生成训练建议时会继续参考这些数据。

全局只会保留一份当前待训练计划。重新推送另一份计划时，会直接替换之前的待训练计划。

## 制定计划

在 **计划** 页面选择一个训练模板后，应用会结合模板和历史训练记录生成下一次训练建议。你可以先修改本次重量、次数和组数，确认后再推送为当前待训练计划。

训练模板代表长期规则，例如动作、目标次数区间、计划组数和起始重量。修改模板只影响以后生成的新建议，不会改变已经推送的当前待训练计划。

### 重新生成

点击 **重新生成**，会按照当前模板和最新训练历史重新计算下一次训练建议。

如果你已经手动调整过建议，而模板或训练历史后来发生变化，应用会让你选择保留当前调整，或者按照最新数据重新生成。

### ChatGPT 修改模板

如果通过 ChatGPT 提出了训练模板修改，计划页会显示待确认内容。

点击 **确认修改** 后，模板会立即更新，并自动重新生成对应的下一次训练建议。已经推送的当前待训练计划不会被一起改掉。

## 训练时怎么记录

训练页支持记录：

- 重量
- 次数
- RIR
- 每组是否完成
- 本次临时增加或减少的组数

训练中的输入会自动保存在当前设备。即使刷新页面或重新打开应用，也可以继续填写。

保存训练后，实际完成的数据会进入历史记录，当前待训练计划也会自动清空。

## 历史、趋势和身体数据

在 **历史** 页面可以查看已经完成的训练。

在 **趋势** 页面可以查看动作表现随时间的变化。

还可以记录：

- 体重
- 胸围
- 腰围
- 臂围

## 多设备同步

如果只在一台设备上使用，可以完全不配置 GitHub。

如果需要在手机和电脑之间同步，建议单独创建一个 **Private GitHub repository** 作为训练数据仓库。

第一次配置：

1. 创建一个 Private GitHub repository。
2. 创建一个 Fine-grained personal access token，只给这个仓库必要的 Contents 读写权限。
3. 打开 **设置 → GitHub 同步**。
4. 填写 GitHub 用户名、私有仓库名和 token。
5. 保存同步信息。

在新的设备上，配置同一个私有仓库后，从 GitHub 合并最新数据即可继续使用。

如果不同设备同时修改了需要人工处理的数据，应用会提示冲突，而不是直接静默覆盖。

## 本地备份

在 **设置 → 本地备份** 中可以：

- 导出 JSON 备份
- 导入以前的 JSON 备份
- 清理当前设备上的训练数据

迁移设备、进行较大的模板调整，或者只是想多保留一份副本时，都可以先导出备份。

GitHub 同步凭据不会包含在训练数据备份中。

## 安装为 App

练了么是一个 PWA。

在支持 PWA 的浏览器中，可以通过浏览器菜单或页面提供的安装入口，把它添加到手机主屏幕或电脑桌面。

安装后可以像普通 App 一样打开。已经缓存的界面资源可以离线加载，但 GitHub 同步仍然需要网络连接。

## 更新异常时

如果更新后明显还是旧页面，或者怀疑缓存没有正确刷新，可以打开：

```text
rescue.html
```

它会清理 Service Worker 和静态缓存，然后重新加载最新版本，不会删除已经保存在浏览器中的训练数据。
