# 练了么（Fitness PWA）

`fitness_pwa` 是一个给个人日常力量训练使用的训练记录 PWA。项目重点放在记录训练过程、回看历史、观察进步趋势，以及在手机和电脑之间同步自己的训练数据。

应用采用 local-first 设计：训练计划、训练历史和身体数据默认保存在当前设备浏览器中。需要跨设备使用时，可以选择将数据同步到一个单独的 Private GitHub repository。

## 主要功能

- 记录每组训练的重量、次数、RIR 和完成状态。
- 保存训练计划，并在训练页直接调整动作、组数、次数区间、默认重量和重量档位。
- 自动保存尚未完成的训练输入，刷新页面或重新打开浏览器后可以继续。
- 查看训练历史。
- 查看单个动作的训练趋势。
- 记录体重、胸围、腰围和臂围。
- 导出和导入本地 JSON 备份。
- 可选使用 Private GitHub repository 进行多设备增量同步。
- 支持安装为 PWA，并缓存应用静态资源供离线打开。

## 数据保存方式

默认情况下，训练数据保存在当前浏览器的 IndexedDB 中，包括：

- 训练计划
- 训练历史
- 身体数据
- 当前训练草稿

项目没有 Analytics、广告或第三方统计 SDK。

如果启用 GitHub 同步，训练数据会额外保存到你自己创建的 Private GitHub repository 中。远端数据使用普通 JSON，因此拥有该 Private repository 访问权限的人可以直接读取其中的内容。

## 部署

这是一个纯静态项目，不需要 npm、打包器或构建步骤。

最简单的方式是使用 GitHub Pages：

1. Fork 或复制本仓库。
2. 将静态文件保留在仓库根目录。
3. 在 GitHub 仓库的 Pages 设置中选择从 `main` 分支根目录发布。
4. 打开生成的 Pages 地址即可使用。

也可以部署到任何支持 HTTPS 静态文件托管的平台。

PWA、Service Worker 和 GitHub API 都依赖浏览器安全环境，正式使用时建议通过 HTTPS 访问。

## 第一次使用

全新浏览器中没有训练计划时，训练页会显示空状态。当前有两种常用初始化方式。

### 方法一：从已有 GitHub 数据恢复

如果你已经在另一台设备使用过这个应用：

1. 先完成下面的 GitHub 同步配置。
2. 在“设置”页面点击“从 GitHub 合并”。
3. 云端训练计划、训练历史和身体数据会合并到当前设备。

### 方法二：导入本地备份

如果你有以前导出的训练备份：

1. 打开“设置”。
2. 选择“导入备份 JSON”。
3. 选择对应的 `fitness-backup-*.json` 文件。

训练计划加载后，可以直接在训练页调整动作配置。

## 配置 Private GitHub 同步

### 1. 创建数据仓库

单独创建一个 Private GitHub repository，例如：

```text
fitness-data-private
```

建议将程序仓库和训练数据仓库分开。公开的 `fitness_pwa` 仓库只保存程序文件，Private 数据仓库专门保存个人训练数据。

### 2. 创建 Fine-grained personal access token

建议只授权刚刚创建的数据仓库，并只授予：

- Contents: Read and write
- Metadata: Read

不要给 Token 添加与同步无关的仓库权限。

### 3. 在应用中填写同步信息

打开“设置 → GitHub 同步”，填写：

```text
GitHub 用户名
Private 仓库名
Fine-grained token
```

然后点击“保存本机同步信息”。

这些信息会保存在当前浏览器中。Token 不会被提交到公开程序仓库，也不会进入导出的训练备份 JSON。

应用会在同步前检查目标仓库，Public repository 会被拒绝。

## 第一次同步

如果当前设备已经有完整训练数据：

1. 配置 GitHub 同步。
2. 点击“增量同步”。
3. 应用会创建远端训练计划、训练记录、身体记录和 manifest。

如果当前设备是新设备：

1. 先配置相同的 GitHub 数据仓库。
2. 点击“从 GitHub 合并”。
3. 等待计划和历史数据下载到本机。

## 多设备日常使用

建议使用下面的顺序：

1. 换到一台设备后，先点“从 GitHub 合并”或训练页中的“拉取最新计划”。
2. 正常完成训练并保存。
3. 训练结束后点“增量同步”。
4. 下一台设备继续使用前再次拉取。

训练记录和身体记录按条目合并，新记录不会覆盖另一台设备已经存在的历史。

训练计划会单独进行 revision 冲突检测。如果两台设备在上一次同步之后都修改过训练计划，应用会阻止直接覆盖，并要求先合并后再明确选择要使用的计划版本。

## 训练计划调整

训练计划加载后，可以在训练页直接维护单个动作，包括：

- 动作名称
- 组数
- 最低次数
- 最高次数
- 默认重量
- 重量档位
- 备注
- 是否为可选动作

也可以新增或删除动作。

训练历史会保留，因此后续修改当前计划不会删除已经保存的旧训练记录。

## 本地备份

“设置 → 本地备份”提供三个功能：

- 导出明文备份 JSON
- 导入备份 JSON
- 删除当前设备上的训练计划、训练历史和身体数据

建议在大幅调整训练计划、迁移设备或修改同步配置之前手动导出一份本地备份。

## 安装为 PWA

在支持 PWA 的浏览器中，可以将“练了么”安装到桌面或手机主屏幕。

如果页面顶部出现“安装”按钮，可以直接使用该按钮。其他浏览器也可以通过浏览器菜单中的“安装应用”或“添加到主屏幕”完成安装。

安装后应用会以独立窗口运行。Service Worker 会缓存静态资源，因此已经成功加载过的版本可以在离线状态下打开并记录本地数据。

GitHub 同步仍然需要网络连接。

## 缓存异常恢复

如果发布新版本后出现旧静态资源没有更新、页面无法正常启动等缓存问题，可以打开：

```text
rescue.html
```

该页面只用于清理 Service Worker 和静态缓存，不会删除 IndexedDB 中的训练计划、训练历史和身体数据。
