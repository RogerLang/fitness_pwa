加密同步

可选功能。数据在浏览器内用 AES-256-GCM 加密后，再上传到你指定的 Private GitHub 仓库。公开的 Pages 仓库不会保存训练数据。

隐私说明

Token 和同步密码不会写进公开仓库，也不会被同步到云端。仓库地址可保存在本机；Token/密码默认只保留在当前页面内存中，刷新后需重新输入。上传前会检查目标仓库 visibility 必须为 private。
