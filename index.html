隐私与冲突说明

GitHub 用户名、仓库名和 Token 可保存在当前浏览器的 IndexedDB 中，不会进入公开 Pages 仓库或导出的训练备份。同步数据在 Private 仓库中以普通 JSON 保存，因此任何能访问该 Private 仓库的人都可以读取训练内容。应用会检查同步目标必须为 Private repository。记录文件名使用本地记录 ID 的 SHA-256，不直接暴露训练日期。若两台设备都修改过训练模板或本次计划，应用会检测 revision 冲突并阻止静默覆盖。
